# Interactive Rating Component

My solution to the [Interactive rating component](https://www.frontendmentor.io/challenges/interactive-rating-component-koxpeBUmI) challenge on Frontend Mentor. A feedback card where the user picks a rating from 1 to 5 and submits it.

## Features

- Select a rating from 1 to 5, with the active choice highlighted
- Submit switches to a thank-you state showing the selected rating
- Hover states on the rating buttons and submit button

## Built with

- Semantic HTML
- CSS with Flexbox and transitions
- Vanilla JavaScript for selection and state

## Run locally

No build step or dependencies. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
